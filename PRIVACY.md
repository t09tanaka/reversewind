# Privacy Policy — Reversewind

## Overview

Reversewind is a Chrome extension that converts web page elements into HTML + Tailwind CSS code and copies it to your clipboard. All processing is performed entirely on your local device.

## Data Collection

Reversewind does **not** collect, store, transmit, or share any user data.

## What the extension accesses

- **Page DOM and CSS**: The extension reads the structure and computed styles of the element you right-click on. This data is used solely to generate the HTML + Tailwind CSS output and is never stored or transmitted.
- **Clipboard**: The generated code is copied to your local clipboard. No data is sent to any external server.

## Permissions

- `contextMenus`: Adds a "Reversewind: Copy" option to the right-click menu.
- `activeTab`: Allows the extension to interact with the current tab only when you use the context menu.
- `clipboardWrite`: Allows copying the generated code to your clipboard.

## Third-party services

Reversewind does not use any third-party services, analytics, tracking, or external APIs.

## Changes

If this policy changes, updates will be posted in this repository.
